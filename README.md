
README.md
RU:
Веб-приложение «Дайджест Спорта» с часами, погодой в Астане, расписанием футбольных матчей топ-лиг, интерактивным таймером и звуком судейского свистка.
 Технологии: HTML5, CSS3, JavaScript (Vanilla), Open-Meteo API, Web Audio API.
 Запуск: Сохраните код в ⁠index.html⁠ и откройте в браузере.

KK:
«Спорт Дайджест» веб-қосымшасы: уақыт, Астанадағы ауа райы, топ-лигалардың матч кестесі, интерактивті таймер және төрешінің ысқырық дыбысы.
 Технологиялар: HTML5, CSS3, JavaScript (Vanilla), Open-Meteo API, Web Audio API.
 Іске қосу: Кодты ⁠index.html⁠ файлына сақтап, браузерде ашыңыз.

EN:
"Sports Digest" web application featuring a clock, Astana weather, top league football schedules, an interactive timer, and a synthesized referee whistle sound.
 Technologies: HTML5, CSS3, JavaScript (Vanilla), Open-Meteo API, Web Audio API.
 Usage: Save the code into an ⁠index.html⁠ file and open it in any browser.
